*********************************** Объекты Базы данных ***********************************

** Основной объект хранения данных в БД:
- Столбцы определенных типов
- Строки
- Данные в ячейках

** Таблицы(PostgreSQL, GreenPlum):
- Постоянные
- Временные
- Нежурналируемые
- Внешние
- Представления
- Стандартные объекты
- Сохраняются на диске
- Журналируются
- ACID compliant

** Типы данных - доступные способы представления данных в БД:
- Числовые
- Символьные
- Двоичные
- Логические
- Дата/Время
- Перечисляемый
- Массивы
- Составные
- Диапазоны
- Геометрические
- Сложносоставные
- Пользовательские

** Ограничения целостности:
- Первичный ключ (Primary key)
- Внешний ключ (Foreign key)
- Уникальность (Unique)
- Обязательность (Not NULL)
- Проверка (check)
- Исключение (exclude)

** Индексы:
+ Ускорение доступа к данным
- Дополнительное место
- Дополнительные ресурсы в словаре данных
- Больше ресурсов при Insert\Update
- Отдельное обслуживание

** Основные виды/типы индексов:
- BTree
- Hash - PostgreSQL only
- GIST
- SP-GIST
- GIN
- BRIN
- Bitmap

** Последовательности:
Генерация уникальных номеров:
- Отдельный объект
- Поле типа SERIAL

** Триггеры
Процедуры при возникновении событий в БД
- DDL
- Update
- Insert
- Delete

** Пользовательские функции
Любые действия пользователя на языках:
- PL\PGSQL
- PL\Python
- PL\Perl
- PL\TCL
- C

** Секции
Разбиение по:
- Дата
- Диапазон дат/времени
- Список значений
- Диапазон значений

** Правила
Переписывание SQL:
- Вставка
- Замена
- Удаление
